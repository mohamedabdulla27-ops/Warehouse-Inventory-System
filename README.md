# Warehouse & Crate Inventory Management System

A modular, multi-threaded Java application built to demonstrate advanced Object-Oriented Programming (OOP) principles, concurrency patterns, and robust error handling through a simulated warehouse inventory domain.

## Architecture & Modules
- **`core`**: Encapsulation, constructors, static state tracking, and user packages.
- **`input`**: CLI console data capture via `Scanner`.
- **`catalog`**: Inheritance and runtime polymorphism hierarchies.
- **`contracts`**: Abstract classes and multiple interface implementations.
- **`exceptions`**: Custom business logic error handling.
- **`concurrency`**: Multithreading (`Thread`/`Runnable`), Inter-thread communication (`wait`/`notify`), and Deadlock simulation.
